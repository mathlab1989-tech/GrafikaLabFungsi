Modul Pembelajaran

1. Konsep Lingkaran Satuan (Unit Circle)

1 / 4

Lingkaran satuan (Unit Circle) merupakan dasar penting geometri trigonometri. Lingkaran ini berpusat di $(0,0)$ dengan jari-jari $r = 1$. Setiap titik pada keliling lingkaran mewakili sudut putar $\theta$.

Koordinat Titik $P(x,y)$

Untuk sembarang sudut $\theta$, koordinat $(x,y)$ didefinisikan sebagai:

$$P(x,y) = (\cos\theta, \sin\theta)$$
  • Panjang alas horizontal $x = \cos\theta$
  • Tinggi tegak vertikal $y = \sin\theta$
  • Rasio kemiringan $\tan\theta = \frac{\sin\theta}{\cos\theta} = \frac{y}{x}$

Nilai Sudut Istimewa Kuadran I

$\theta$ $0^\circ$ $30^\circ$ $45^\circ$ $60^\circ$ $90^\circ$
$\sin$ $0$ $\frac{1}{2}$ $\frac{1}{2}\sqrt{2}$ $\frac{1}{2}\sqrt{3}$ $1$
$\cos$ $1$ $\frac{1}{2}\sqrt{3}$ $\frac{1}{2}\sqrt{2}$ $\frac{1}{2}$ $0$

Tiga fungsi dasar trigonometri memiliki pola gelombang dan sifat-sifat periodik yang khas saat digambarkan pada koordinat Kartesius.

Fungsi Sinus
y = sin(x)
  • Dimulai dari: Titik asal $(0,0)$
  • Amplitudo dasar: $1$ (Rentang $[-1, 1]$)
  • Periode dasar ($T$): $360^\circ$ ($2\pi$ rad)
  • Puncak Maksimum: Pada $x = 90^\circ$
  • Lembah Minimum: Pada $x = 270^\circ$
Fungsi Kosinus
y = cos(x)
  • Dimulai dari: Puncak $(0,1)$
  • Amplitudo dasar: $1$ (Rentang $[-1, 1]$)
  • Periode dasar ($T$): $360^\circ$ ($2\pi$ rad)
  • Memotong sumbu-X: $x = 90^\circ, 270^\circ$
  • Lembah Minimum: Pada $x = 180^\circ$
Fungsi Tangen
y = tan(x)
  • Bentuk kurva: Gelombang terputus
  • Periode dasar ($T$): $180^\circ$ ($\pi$ rad)
  • Asimtot Tegak: $90^\circ, 270^\circ$ ($\cos x = 0$)
  • Rentang (Range): $(-\infty, +\infty)$

Dengan memodifikasi nilai parameter $A, B, C,$ dan $D$, grafik trigonometri dasar dapat diregangkan, dipampatkan, atau digeser.

Bentuk Umum Persamaan Transformasi:
$$y = A \cdot \sin(B(x - C)) + D$$
A Amplitudo & Refleksi ($A$)

Amplitudo $= |A|$. Menentukan tinggi gelombang dari midline. Jika $A < 0$, grafik dicerminkan (dibalik) terhadap sumbu mendatar.

B Frekuensi & Periode ($B$)

Periode $T = \frac{360^\circ}{|B|}$. Nilai $B$ menentukan banyaknya gelombang lengkap dalam rentang $360^\circ$.

C Pergeseran Fase Horizontal ($C$)

Menentukan pergeseran horizontal. Jika $(x - C)$ dengan $C > 0$, grafik bergeser ke kanan sejauh $C$.

D Pergeseran Vertikal / Midline ($D$)

Menentukan posisi garis tengah gelombang (midline $y = D$). Grafik bergeser ke atas jika $D > 0$.

Mari pelajari langkah demi langkah cara menentukan persamaan dari sebuah grafik trigonometri yang telah ditransformasikan.

Contoh Soal Analisis Grafik

Sebuah gelombang sinus memiliki titik tertinggi di $y = 5$ dan titik terendah di $y = -1$. Jika periodenya $180^\circ$ tanpa geseran horizontal, tentukan persamaannya!

Langkah Penyelesaian:
1. Cari Midline ($D$): $D = \frac{Y_{max} + Y_{min}}{2} = \frac{5 + (-1)}{2} = 2$
2. Cari Amplitudo ($A$): $A = Y_{max} - D = 5 - 2 = 3$
3. Cari Nilai $B$: $B = \frac{360^\circ}{\text{Periode}} = \frac{360^\circ}{180^\circ} = 2$
4. Persamaan Akhir: $y = 3\sin(2x) + 2$

Tentang Lab Maya ini

Aplikasi ini dikembangkan untuk memfasilitasi pembelajaran matematika berbasis Guided Discovery Learning (Penemuan Terbimbing) pada topik Grafik Fungsi Trigonometri.

Langkah Eksplorasi:

  1. Buka menu 1. Lingkaran Satuan untuk mengamati bagaimana nilai sudut membentuk gelombang trigonometri secara geometris.
  2. Gunakan menu 2. Karakteristik & Transformasi untuk menggeser slider $A, B, C, D$ dan menemukan peran masing-masing parameter.
  3. Uji pemahaman intuitifmu di menu Tantangan.
  4. Selesaikan Evaluasi dan dokumentasikan temuanmu di jurnal Refleksi.
